# 🧬 Bioinformática desde Cero

## Nivelación para alumnos de nuevo ingreso

Este espacio ha sido creado como material de apoyo para la **nivelación en herramientas de Bioinformática** de los alumnos de nuevo ingreso al laboratorio.

El objetivo es que todos los alumnos puedan adquirir una base común para trabajar con herramientas computacionales aplicadas a las ciencias biológicas.

## 💻 ¿Qué aprenderemos?

A lo largo de esta nivelación trabajaremos progresivamente con:

- 🖥️ Terminal y Linux
- 🐚 Bash
- 🐍 Python
- 📊 R y RStudio
- 🧬 Archivos y datos biológicos
- 🔬 Análisis de secuencias
- 🦠 Genómica bacteriana
- 📈 Visualización de datos
- 🧪 Proyecto final

## 👩‍🔬 ¿A quién está dirigido?

Principalmente a alumnos de nuevo ingreso que no cuentan con experiencia previa en terminal, programación o análisis bioinformático.

Los alumnos que ya cuentan con experiencia en estas herramientas también pueden utilizar este material como referencia y repaso.

## 🚀 ¿Cómo utilizar este material?

Se recomienda seguir los módulos en orden, realizar los ejercicios y ejecutar personalmente cada uno de los comandos indicados.

> **Importante:** No te limites a copiar los comandos. Es necesario ejecutarlos y comprender qué hace cada uno.
