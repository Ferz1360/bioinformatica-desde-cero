# 💻 Módulo 02 — La Terminal

## ¿Qué es una terminal?

La terminal es una herramienta que nos permite comunicarnos con 
la computadora mediante texto.

En lugar de utilizar únicamente ventanas, botones y menús, 
podemos escribir instrucciones llamadas **comandos** para 
indicarle a la computadora qué queremos hacer.

Por ejemplo:

```bash
pwd
